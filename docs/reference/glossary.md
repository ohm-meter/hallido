# Reference: Glossary

Product name: **Hallido** (“Scenes & alarms for Sonos”, [ADR 0020](../adr/0020-product-name-hallido.md)). CLI and service keep the name `sonos-agent`.

Terms used in the docs, the web app and the API, with the German translation
used by the web app's German locale. Keep new texts consistent with this list.

## Never translated

API paths, JSON keys, error codes (`speaker_unreachable`, `playback_failed`,
`rate_limited`, …), environment variables (`SRA_*`), CLI commands and flags,
file paths, config values and the token placeholder `BITTE-AENDERN`.
