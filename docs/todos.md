# Roadmap

Open items, roughly prioritized. Suggestions and help are welcome as an issue
or pull request — see [CONTRIBUTING.md](../CONTRIBUTING.md).

| Priority | Topic |
|----------|-------|
| P2 | More hardware cases: large groups, Roam/Move |
| P2 | Config sync: merge modes (`replace`, `prune`) and CLI `sonos-agent config sync-speakers` |
| P2 | Rate limit per real client IP behind a reverse proxy |
| P2 | Aliases for speaker names ([ADR 0006](adr/0006-auto-discovery-lan.md), option B) |
| P2 | Read the initial volume live from the speaker (`GetVolume`) |
| P3 | Dedicated Homey app (triggers/cards) |
| P3 | `sonos-agent update` from release binaries instead of a Git build (no Go required) |
| P2 | Language switch in the web app and localized API error texts — see [i18n roadmap](plans/i18n-roadmap.md) |
| P3 | Rename binary/CLI to `hallido` (migration plan, ADR) |
